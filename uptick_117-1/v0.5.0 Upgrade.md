# Uptick – v0.5.0 Upgrade Announcement

Dear Uptick Validators,

We are excited to announce that the Uptick Mainnet will be upgraded to v0.5.0.

- **Target Block Height:** 19,730,130
- **Estimated Time:** October 19th, 2026, at 10:00:00 UTC
- **Commit Hash:** 937ceef556181a68498d29ca21208d7172101653
- **Upgrade Plan Name:** `v0.5.0` (must be submitted verbatim)


## Changed

v0.5.0 is a **one-hop upgrade from v0.3.3** (cosmos/evm v0.6.2 + ibc-go v10). The testnet executed the
v0.4.0 and v0.4.1 change sets as two separate plans; the mainnet replays **both inside one governance
plan** named `v0.5.0`.

- **EVM:** ethermint → cosmos/evm. **IBC:** legacy ibc-go v8 fork → ibc-go v10.
- **Consensus deps:** Cosmos SDK v0.53.8, CometBFT v0.38.25, Go 1.25.13.
- **IBC voucher ERC20 repair:** `decimals()` stops reporting 0 for IBC-derived ERC20 (it was making wallets,
  explorers and DEX front-ends read every IBC voucher balance as 10^18 times its value), and existing
  vouchers gain the token pair they could never acquire after v0.4.0 deleted the legacy pairs.
- **Voucher settlement:** the `v0.5.0` handler settles IBC voucher pairs at the upgrade height and reports
  its counts (`settled` / `stale_cleared` / `kept` / `pairs_deleted`) in the upgrade log line. **Validators
  and operators should capture that line** — it is the only record of what the settlement did.
- **CometBFT 0.38.25 node-local default changes** (not consensus rules): `block_time_tolerance` defaults
  to 60s.

  
## For Validators Running Cosmovisor

Please refer to our [Cosmovisor](https://upticknft.gitbook.io/uptick-network-documentation/guides/quickstart/cosmovisor) Setup Guide.

Please Note: Cosmovisor will perform a full backup unless you set the environment variable: `UNSAFE_SKIP_BACKUP=true`

```bash
# make a dir if you've not
mkdir -p $DAEMON_HOME/cosmovisor/upgrades/v0.5.0/bin

# build from source. Go 1.25.13+ is required.
git clone https://github.com/UptickNetwork/uptick.git
cd uptick
git checkout v0.5.0
make install
cp $GOBIN/uptickd $DAEMON_HOME/cosmovisor/upgrades/v0.5.0/bin/
```

With a release binary, the version check should read:

```bash
$DAEMON_HOME/cosmovisor/upgrades/v0.5.0/bin/uptickd version --long
#commit: 937ceef556181a68498d29ca21208d7172101653
#cosmos_sdk_version: v0.53.8
#go: go version go1.25.13 linux/amd64
#name: uptick
#server_name: uptickd
#version: v0.5.0
```

## For Validators NOT Using Cosmovisor

The chain will halt at the target block. Please manually update your binary as follows:

```bash
git clone https://github.com/UptickNetwork/uptick.git
cd uptick
git checkout v0.5.0
make install    # Go 1.25.13+ required

uptickd version --long
```
